# phomv has moved

phomv now lives in **[chinny-labs](https://github.com/chinny-labs)**:

- Source: <https://github.com/chinny-labs/phomv>
- Docs: <https://chinny-labs.github.io/phomv/>
- Homebrew: `brew untap phomv/tap; brew install chinny-labs/tap/phomv`
- Go: `go install github.com/chinny-labs/phomv/cmd/phomv@latest` (v0.2.1 and later)
- winget: `winget install phomv.phomv` (unchanged)
